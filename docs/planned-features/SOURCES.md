# Sources and evidence boundary

Access date: 2026-10-28. Sources were researched through web retrieval for this package. No hardware measurements, DSP implementation benchmarks or listening studies were performed. Product limits/defaults/algorithms labeled proposed are authored design choices, not numerical conclusions from these sources. Short descriptions below identify exactly what each source supports.

| ID | Primary source / locator | Evidence used and limit |
|---|---|---|
| S01 | [Steinberg VST3 Processing FAQ](https://steinbergmedia.github.io/vst3_dev_portal/pages/FAQ/Processing.html), bypass, latency, state and realtime-call questions | Audio-thread restrictions, host bypass and lifecycle handling. Does not validate CircuitDrift DSP. |
| S02 | [Steinberg Parameters and Automation](https://steinbergmedia.github.io/vst3_dev_portal/pages/Technical%2BDocumentation/Parameters%2BAutomation/Index.html), IDs and automation recording/playback | Stable IDs, host edit gestures and independent automation; basis for derived macro values that do not rewrite another automated parameter. |
| S03 | [Steinberg ProcessModes](https://steinbergmedia.github.io/vst3_doc/vstinterfaces/namespaceSteinberg_1_1Vst.html), ProcessModes and RestartFlags | Realtime/prefetch/offline timing differ; latency-change notification. IPC scheduling limitations are engineering inferences from this and host architecture, not a guaranteed host ordering API. |
| S04 | [JUCE Oversampling](https://docs.juce.com/master/classjuce_1_1dsp_1_1Oversampling.html), class description, constructor, initProcessing/getLatencyInSamples | 2/4/8/16x factors, FIR/IIR tradeoffs, preallocation and latency. Constructor factor is log2 of actual rate; don't pass 16 expecting 16x. Filter targets here require independent tests. |
| S05 | [JUCE AudioPlayHead::PositionInfo](https://docs.juce.com/master/classjuce_1_1AudioPlayHead_1_1PositionInfo.html), description and timing getters | Host timing fields are optional. Tempo fallback/phase rules are our design. |
| S06 | Gillespie and Schachter, [Model Bending: Teaching Circuit Models New Tricks](https://www.dafx.de/paper-archive/2022/papers/DAFx20in22_paper_19.pdf), DAFx 2022, especially sections 2–3 | Circuit-inspired creative processing differs from exact hardware emulation; modeling/passivity concerns. Paper is CC BY 4.0; no code copied here. It does not supply this product's tube/aging coefficients. |
| S07 | Denniss and Bradley, [RFC 8252: OAuth 2.0 for Native Apps](https://www.rfc-editor.org/rfc/rfc8252.html), sections 4, 7, 8.1/8.5/8.12 | System-browser native authentication and PKCE/public-client constraints. Backend/provider remains unselected. |

Native adapter not built. |
| S11 | ROHM, [How to Use Thermal Models](https://fscdn.rohm.com/en/products/databook/applinote/discrete/sic/common/how_to_use_thermal_models_an-e.pdf), February 2020 Rev.001, pp.1–6 | Thermal RC representation, heat capacity J/K, conductance/power relationships. Source concerns SiC power devices; its numeric coefficients are NOT transferable to vintage tubes/resistors and none are used here. |
| S12 | de Cheveigne and Kawahara, [YIN, a fundamental frequency estimator for speech and music](https://doi.org/10.1121/1.1458024), JASA 111(4), 1917–1930 (2002) | Research lead only: bibliographic metadata/abstract found. | S15 | [free-audio/clap-juce-extensions](https://github.com/free-audio/clap-juce-extensions), README support/limitations/CMake | Third-party CLAP adapter exists, with wrapper limitations; qualification required. No claim of native JUCE CLAP parity. |
| S16 | [Apple AVAssetWriter](https://developer.apple.com/documentation/avfoundation/avassetwriter) and [startSession](https://developer.apple.com/documentation/avfoundation/avassetwriter/startsession%28atsourcetime%3A%29) | Official API and source-time session concept located; full JS reference was not readable in this retrieval. Adapter details and codec support must be verified against installed Apple SDK docs before coding. |

## Required next research

Produce per-device manifest, characteristic curves, admissible bias/supply/temperature ranges, dissipative-power accounting and independent reference tests for every shipping component. Pin complete sources with page/figure and reuse rights. Especially investigate 12AX7/EF86, chosen BJT/JFET, rectifiers, capacitor absorption/leakage/ESR, carbon/metal/wirewound noise and transformer materials.

Do not infer real aging from the creative timeline table, real thermal fluctuations from the colored-noise generator, measured harmonic targeting from a proposed LUT procedure, or physically exact cross-talk from the delayed IPC surrogate. Those are explicitly designed behaviors until validated.

Scientific/technical sources were used as primary sources. No copied implementation, bundled datasheet asset or third-party schematic is included.
