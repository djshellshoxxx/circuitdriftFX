# Open implementation and research gates

These are concrete blockers to the corresponding claims/releases, not excuses to omit planned features. Reversible UI/data work may proceed using deterministic synthetic fixtures.

| Gate | Impact | Proposed resolution / closure evidence |
|---|---|---|
| G01 Per-device circuit manifests and calibration | Physical engine, macros, harm targeting, inspector units, blueprint catalogue | Execute original research prompt; choose actual devices/reference schematics; publish coefficient provenance, bounds, independent curves and residuals |
| G02 Macro/timeline sonic calibration | Artistically useful settings, age/fault defaults | Blind level-matched audition plus measured domain/alias/DC tests; keep authored table versioned |
| G03 Solver/filter implementation and budgets | 4x/16x, realtime, custom graph cost limits | Build reference harness, measure factory/max graphs on listed CPUs and rates; freeze coefficients/solver caps; reject over-budget graphs |
| G04 1x <1.5% target and <120 MB idle | Performance claim | Count actual callback p99/deadline and attributable CPU/GPU allocations, including history; optimize or report miss rather than change definition |
| G05 IPC host behavior and offline co-render | Multi-instance reliability | Test per-host process/sandbox/prefetch matrix; implement broker and deterministic influence bundle harness |
| G06 Cloud provider, auth domain and operations | Community release | Select backend/provider/region, register native OAuth callbacks, specify availability, moderation and retention operations; credentials never committed |
| G07 Native media encoders | MP4/GIF exporter | Verify installed SDK APIs/codecs, implement adapters, run A/V timing and resource tests; document fallback |
| G08 AAX access/signing and supported host versions | AAX release | Obtain required SDK/testing/signing through owner workflow; validate signed plugin in retail host |
| G09 JUCE 8 pin, licensing, CLAP adapter revision | Reproducible builds/formats | Record exact commits/releases, license choice and adapter behavior in build ADR |
| G10 Monophonic pitch estimator | Key tracking from audio | Inspect full primary pitch-estimation research, compare detector candidates on fixture corpus, calibrate confidence/octave-error thresholds |
| G11 Renderer/backends/HiDPI accessibility | Workbench performance | Choose verified GPU adapter for each OS; test 2D fallback, focus and scale on hosts |
| G12 Checkpoint/model migration policy | Exact session continuity | Implement compatible snapshots and explicit reset fallback; test across Fs/version changes |

No paid service has been provisioned, account created, message sent, binary built or feature implemented as part of this planning update.
